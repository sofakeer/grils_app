# 四叶草蒙版效果实现指南

## 目标效果

你想要的效果是：**四叶草形状的蒙版里面显示图片，外面是透明的**，就像你提供的参考图片一样。

## 实现方法

### 1. 进入花瓣蒙版测试页面
- 在主页面点击右侧的**红色花朵按钮**（🌺）
- 进入花瓣蒙版测试页面

### 2. 设置最佳参数
为了获得四叶草效果，请按以下设置：

#### 花瓣数量：4片
- 使用滑块将花瓣数量设置为4
- 4片花瓣正好形成四叶草形状

#### 花瓣大小：30%
- 使用滑块将花瓣大小设置为30%
- 这个大小最适合四叶草效果

#### 蒙版反转：关闭
- 保持反转蒙版开关为关闭状态
- 这样图片会显示在花瓣内部

### 3. 选择背景图片
点击右侧的切换按钮，选择以下背景之一：
- **码头风景**：蓝色渐变，模拟码头和天空
- **日落风景**：橙色渐变，模拟日落效果
- **森林风景**：绿色渐变，模拟森林
- **紫色梦幻**：紫色渐变，梦幻效果
- **内衣图片**：你的原始图片

## 技术原理

### 蒙版实现
```dart
// 在花瓣形状内显示图片，外面透明
Stack(
  children: [
    // 背景图片或渐变
    Image.asset(...) 或 Container(gradient: ...),
    // 花瓣蒙版
    CustomPaint(
      painter: FlowerMaskPainter(
        petalCount: 4,        // 四叶草
        petalSize: 0.3,       // 合适大小
        useInvertedMask: false, // 正常蒙版
      ),
    ),
  ],
)
```
